# Корпоративный банк идей

Веб-приложение для сбора и обработки идей сотрудников. Django + PostgreSQL + htmx.

## Что нужно перед началом

- Python 3.12 или новее
- Docker Desktop (для локальной базы PostgreSQL) — либо своя установленная PostgreSQL
- Git

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/<логин>/<репозиторий>.git
cd <репозиторий>
```

### 2. Виртуальное окружение

**Windows (cmd):**
```cmd
python -m venv venv
venv\Scripts\activate.bat
```

**macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Поднять базу данных

```bash
docker run --name bank-idey-db -e POSTGRES_PASSWORD=devpassword -e POSTGRES_DB=bank_idey -p 5432:5432 -d postgres:16
```

### 5. Настроить переменные окружения

Скопируйте образец в рабочий файл:

**Windows (cmd):**
```cmd
copy .env.example .env
```

**macOS / Linux:**
```bash
cp .env.example .env
```

Откройте `.env` и замените `SECRET_KEY` на собственную случайную строку — сгенерировать можно так:
```bash
python -c "import secrets; print(secrets.token_urlsafe(50))"
```

### 6. Применить миграции

```bash
python manage.py migrate
```

### 7. Создать администратора

```bash
python manage.py createsuperuser
```

### 8. Загрузить демонстрационные данные (по желанию)

```bash
python manage.py seed_demo_data
```

Команду можно запускать повторно — не создаёт дублей. Загружает 2 отдела, 6 демонстрационных пользователей, 3 категории и 10 идей, покрывающих все статусы и роли — удобно для быстрой проверки сценариев.

### 9. Запустить сервер

```bash
python manage.py runserver
```

Откройте **http://127.0.0.1:8000/** — сработает автоматический переход на страницу входа.

## Демонстрационные аккаунты

*(появляются после шага 8, пароль у всех одинаковый)*

| Логин | Роль | Отдел |
|---|---|---|
| `employee_sales` | Сотрудник | Отдел продаж |
| `employee_it` | Сотрудник | IT-отдел |
| `manager_sales` | Руководитель | Отдел продаж |
| `manager_it` | Руководитель | IT-отдел |
| `expert_1` | Эксперт | Отдел продаж |
| `expert_2` | Эксперт | IT-отдел |

**Пароль для всех:** `demo12345`

Администратор — учётная запись, которую вы создали на шаге 7, под своим логином и паролем.
